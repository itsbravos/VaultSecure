## VaultSecure 1.0.0

🇧🇷 **Português** · 🇺🇸 [English below](#english)

Primeira versão para instalar no computador. Tudo continua 100% local: nenhuma senha sai do seu aparelho.

### Downloads

| Sistema | Arquivo |
|---|---|
| Windows 10/11 | `VaultSecure-1.0.0-win-x64.exe` |
| macOS (Apple Silicon) | `VaultSecure-1.0.0-mac-arm64.dmg` |
| macOS (Intel) | `VaultSecure-1.0.0-mac-x64.dmg` |
| Linux | `VaultSecure-1.0.0-linux-x86_64.AppImage` |

Prefere não instalar nada? Use no navegador e instale como app (PWA): https://itsbravos.github.io/VaultSecure/

> **Os instaladores ainda não são assinados digitalmente.**
> - **Windows:** se aparecer "O Windows protegeu o computador", clique em *Mais informações → Executar assim mesmo*.
> - **macOS:** clique com o botão direito no app → *Abrir* (só na primeira vez).
> - **Linux:** `chmod +x VaultSecure-*.AppImage` e execute.
>
> Para conferir que o arquivo não foi alterado, compare o SHA-256 com o `SHA256SUMS.txt` deste release.

### Segurança

- **Configurações sensíveis agora são criptografadas**: segredo do 2FA, códigos de emergência e chaves dos certificados deixaram de ficar em texto puro.
- **PBKDF2 com 600.000 iterações** (antes eram 250.000). Cofres existentes são atualizados automaticamente no próximo desbloqueio, que demora um pouco mais só dessa vez.
- **Senha de coação mais forte e indetectável.** ⚠️ Se você já usava uma, defina-a novamente em Configurações (o app avisa).
- **A autodestruição não zera mais ao recarregar a página.**
- **Códigos de emergência do 2FA agora funcionam** na tela de desbloqueio ("Perdeu o celular?"), cada um uma única vez.
- **Ícones de sites via Google vêm desligados por padrão**, para que a lista dos seus sites não seja enviada a terceiros.
- **A versão web ganhou Content Security Policy e bloqueio de iframe.**

### English

First installable desktop version. Everything stays 100% local: no password ever leaves your device.

**Downloads:** Windows `.exe`, macOS `.dmg` (Apple Silicon `arm64` / Intel `x64`), Linux `.AppImage`. Or use it in the browser and install it as an app (PWA): https://itsbravos.github.io/VaultSecure/

> **The installers are not code-signed yet.** On Windows choose *More info → Run anyway*; on macOS right-click the app → *Open* the first time; on Linux `chmod +x` the AppImage. Check the SHA-256 against `SHA256SUMS.txt`.

**Security**
- **Sensitive settings are now encrypted**: the 2FA secret, emergency codes and certificate keys.
- **PBKDF2 raised to 600,000 iterations.** Existing vaults upgrade automatically on the next unlock.
- **Stronger, undetectable duress password.** ⚠️ If you had one, set it again in Settings.
- **The self-destruct counter now survives a page reload.**
- **2FA emergency codes now work** on the unlock screen, single use.
- **Google favicons are off by default.**
- **The web version now ships a Content Security Policy and refuses to run inside a frame.**
